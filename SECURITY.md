# Security policy

Thank you for helping keep Token Sidekick users safe.

## Reporting a vulnerability

Please **don't open a public issue**. Instead, use GitHub's private reporting: **Security → Report a
vulnerability** on this repository. We'll acknowledge it within a few days and keep you updated until it's fixed.

Helpful details: the app version (Settings → About), what an attacker could do, and steps to reproduce.

## Scope

- The Windows app and its installer or auto-updates.
- The Claude Code bridge (`claude-sidekick-bridge.exe`) and the settings it writes.
- Workshop item codes and files: anything that makes a shared item run code or load remote content.
- The store and gallery server, once it's online.

Out of scope: denial of service by flooding, and anything that requires already controlling the user's PC.
