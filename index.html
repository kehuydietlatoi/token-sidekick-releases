🤖 Claude Workshop assistant · MCP

Just ask Claude to dress Token

Token ships with a small MCP server. Turn it on and Claude Code can design, preview and save items straight into your wardrobe.

  1. Switch it on. Settings → Claude Workshop assistant. Token registers itself with claude mcp add for you.
  2. Ask. In Claude Code, say what you want:
    design Token a pirate hat make wings with little straps a galaxy skin with a shiny sheen
  3. Watch it work. Claude reads the house style guide, previews the draft on Token in every mood, fixes anything the safety check rejects, then saves and dresses Token.
  • Off until you turn it on. Nothing listens by default.
  • Local only. It listens on your own PC, behind a private token.
  • Safe by construction. Claude's art goes through the same sanitizer as yours, and it can't delete anything.

Install in a minute

Free during the beta, premium packs included.

  1. Download Token-Sidekick-Setup.exe and run it.
  2. Windows may warn you. The beta isn't code-signed yet (that costs money we'd rather spend on hats), so SmartScreen shows a blue box. Click More info, then Run anyway.
    Windows protected your PCMicrosoft Defender SmartScreen prevented an unrecognized app from starting…
    More info → Run anyway
  3. Connect Claude Code: right-click Token → Settings → Connect. Usage shows up after Claude's next reply. It needs a Pro or Max plan, since only those report limits.

Private by design

Token runs on your PC and minds its own business.

🔒 No prompts, no code

It reads only the usage numbers Claude Code already puts in its status line, plus tool names from hooks. Never your prompts, replies or files.

📡 Nothing sent

The beta has no account and no telemetry. Its only network call is checking GitHub for updates.

↩️ Easy to undo

Connecting backs up your Claude settings first, and Disconnect removes exactly what it added.

🤖 Claude stays local

The Workshop assistant is off by default and only listens on your own PC. It registers through claude mcp add, so the app never edits Claude's config files by hand.

Privacy policy · Terms

FAQ

Is it free?

Yes. During the beta everything is free, including the premium packs. Claim them in the Shop and they're yours to keep.

What does Claude need to design items for me?

Claude Code installed, and the Claude Workshop assistant switched on in Settings. Token registers its local MCP server for you; if that fails, the same card shows a command to copy.

Can I stop Token hopping around?

Yes. Every habit has its own reminder level (Gentle, Loud or Ultra), and the 👀 Preview button in the panel shows what each one does before you pick.

Mac or Linux?

Windows only for now. Tell us if you want another platform, since that decides what comes next.

Which plans and agents work?

Claude Code with a Pro or Max plan (API-key users don't get rate limits, so Token just hangs out). Codex CLI is detected automatically. More agents are planned.

Is it safe to run something unsigned?

The warning only means the installer isn't signed with a paid certificate yet. The app runs in Electron's sandbox, blocks remote pages and links, and updates only from our GitHub releases. Security issues can be reported privately; see our security policy.

How do I uninstall?

Settings → Disconnect first (it restores your Claude settings), then remove it from Windows' Installed apps.
