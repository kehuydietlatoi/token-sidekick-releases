# 🫧 Token Sidekick (beta)

**Token** is a little blob that lives on your Windows taskbar and eats tokens. Its belly is your **Claude Code**
usage meter: hungry and hyper when you have plenty left, a snoring puddle when you've hit your limit. **Codex CLI**
users get a companion critter, **Cody**. Finish todos, habits and focus sessions to collect hats, glasses and skins,
or make your own in the **Workshop**.

## Installing

1. Download `Token-Sidekick-Setup.exe` from the [latest release](https://github.com/kehuydietlatoi/token-sidekick-releases/releases/latest) and run it.
2. The beta isn't code-signed yet, so Windows may say **"Windows protected your PC"**. Click **More info → Run
   anyway**.
3. Right-click Token → **Settings → Connect** to link Claude Code. You'll need a Pro or Max plan, since only those
   report usage limits.

The app updates itself: new versions download in the background and install when you restart it.

## Privacy

Token runs entirely on your PC. It reads the usage numbers Claude Code already shows in its status line, plus
Codex's local log files, and never reads your prompts or code. The beta sends nothing anywhere. It only checks this
page for updates, and the **Send feedback** button opens a GitHub issue that you review before posting.
